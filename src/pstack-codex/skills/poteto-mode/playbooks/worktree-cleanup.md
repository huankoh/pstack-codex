### Worktree and simulator cleanup

**You own the disk and the safety gate.** Archive eligible merged or abandoned git worktrees and prune stale iOS simulators to reclaim space. Every step guards against losing needed work or disrupting a checkout in use.

1. Snapshot and audit. Record `df -h /`, then run `skills/poteto-mode/scripts/worktree-audit.sh` under the installed plugin (principle-build-the-lever). It reads paths from `git worktree list`, never hand-typed, since a hand-typed `myrepo-worktrees/x` misses one that lives at `.worktrees/myrepo/x` (principle-encode-lessons-in-structure). It classifies each worktree by size, age, merge state, uncommitted work, PR state, and the newest chat that touched it, then suggests a bucket. The transcript scan is slow, so run it in a scoped retrieval subagent per [Codex transcript evidence](../../reflect/references/codex-transcripts.md). The audit script's default Claude transcript path is inapplicable; pass an explicitly scoped Codex transcript directory only when its format is suitable for the script. Otherwise mark chat evidence unavailable and corroborate usage with Codex attachments and active processes.
2. The bucket is advice, not permission. The pinned and active chats are the real artifact (principle-prove-it-works). Get that set from the user or your own session list and cross-check every candidate. The lever has marked `safe` a worktree the user had pinned, so the pinned set wins.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan subagents out to read scoped Codex transcripts per [Codex transcript evidence](../../reflect/references/codex-transcripts.md) and report whether the chat is pinned or ongoing and which worktrees it touches (principle-guard-the-context-window, transcripts are bulk). A pinned chat spawns arena and repro trees into sibling worktrees via background subagents, and those are in use even when their names never hit the session list.
4. Preserve work before cleanup. `wip:N` is N tracked uncommitted edits and `scratch:N` is N untracked files. Show and account for both. If the worktree is unused and eligible for recoverable managed archival, preserve needed ignored files separately, archive it without an extra confirmation, and report it. An in-use, primary, pinned, or shared checkout stays. If recoverable archival is unavailable, ask before any destructive removal of uncommitted or needed untracked work. See [Local worktrees](../references/local-worktrees.md).
5. Archive the confirmed managed set with Codex worktree archival. For a manually managed checkout, preserve its work and use Git removal only when permitted by the host and the user's authorization. Do not force-remove a checkout or erase ignored files as a cleanup shortcut. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, your editor's application-support caches, Codex caches and transcripts only after identifying their exact path and preserving records needed by **recall** and Session pickup, package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees archived or pruned, and a one-line reason for each held back (in-use by which chat, or uncommitted work).
