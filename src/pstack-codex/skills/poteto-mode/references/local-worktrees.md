# Local worktrees in Codex

Codex agents share the local filesystem. Reuse a suitable free worktree first. On a host with managed worktree tools, inspect attached worktrees, create from the intended ref only when needed, wait for the returned absolute workspace path, and give it explicitly to its owner. The tool does not move the current chat or child agents. Use a manual Git worktree only when managed creation is unavailable and host instructions permit it. Keep one concurrent writer per physical checkout. Before integrating another worker's changes or cleaning up, confirm the owner has finished, stop its completed or abandoned children, and inspect `git status` and the actual diff. Do not stop an unrelated active task or process to make its checkout eligible for reuse or cleanup.

Archive an unused managed worktree when its work has been accounted for, including uncommitted changes, without an extra confirmation. Managed archival preserves tracked and non-ignored untracked files; preserve any needed ignored files separately first. Preserve primary, pinned, shared, and in-use checkouts. A merged PR alone does not make a checkout disposable. Report what was archived. Where recoverable archival is unavailable, do not treat this as permission to delete unsaved work. Destructive removal or data deletion still needs the user's decision.
