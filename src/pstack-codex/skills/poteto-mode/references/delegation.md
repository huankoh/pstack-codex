# Codex delegation for poteto-mode

Use Codex `spawn_agent` for an assigned subagent role. Its exposed arguments are `task_name`, `message`, and, when supported, `agent_type`, `model`, `reasoning_effort`, and `fork_turns`. It has no `cwd`, `isolation`, `readonly`, or `run_in_background` argument. A dispatched agent runs concurrently with the caller. For a fresh independent brief, use `fork_turns: "none"` when available and supply all essential context and file pointers. Personas under `agents/` or `references/agents/` are prompts to read in the brief, not registered Codex agent types. Have poteto-mode delegates read `skills/poteto-mode/SKILL.md`; have comment reviewers read `skills/poteto-mode/references/agents/comment-sicko.md`. Do not replace a required independent reviewer with the writer.

For a follow-up in the same conversation, reuse the existing poteto delegate through `followup_task` or the host's equivalent resume operation instead of spawning a sibling. If that delegate is no longer resumable, say so and carry its working context into the replacement brief. This continuity rule does not replace a required fresh independent reviewer with an existing writer.

Choose the configured model for the named role from `${CODEX_HOME:-$HOME/.codex}/pstack-models.md`, falling back to the skill's Models section. Pass an explicit `model` and any configured `reasoning_effort`; `session`, `inherit-parent`, or `auto` omit the corresponding argument. Every Luna assignment requests `max`, including panel members. Luna has no `ultra`. If a requested model or effort is unavailable on this host, report the limitation and ask the user to choose a replacement before that step continues. Do not silently substitute or lower effort. Sol inspects decisive sources and decides conclusions after a Luna retrieval task.

Give each writer an exclusive physical worktree and an explicit file scope. The brief names the absolute checkout path and starting revision, says the agent is not alone in the codebase, and requires `pwd`, `git rev-parse --show-toplevel`, and `git rev-parse HEAD` verification before writing. Use that absolute path for every shell command. A branch name or prose-only file fence does not isolate concurrent writers. A read-only brief is an instruction, not an enforced sandbox unless the host provides one. Review each delegate's actual diff and produce your own summary. Check agent status and stop abandoned or completed children through the host's agent lifecycle tools; a completion notification alone does not prove a process exited. If concurrency is unavailable, dispatch separate agents sequentially while preserving roles and counts. If no subagent capability is available, report the required independent step as unavailable. Use a skill's explicit degraded sequential fallback only when it provides one, label the loss of independence, and do not count one actor as multiple independent reviewers or claim the required independent check passed.

For a long-running program, use Codex's available agent status and wait tools to drain workers. Keep the existing owner, verifier, and coordinator separation and the existing audit cadence. Do not claim background execution or future wakeups merely because a worker was spawned.
